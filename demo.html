Example workflows

Three things to try in the demo.

Each workflow follows how Ada Okafor, our fictional investor, uses the planner. The demo's own sample plan uses different figures.

About 15 minutes

Build a first plan

  1. Open Plan settings and enter a target in today's money and a target age.
  2. Enter a monthly amount and a yearly step-up.
  3. Set target weights for each asset class.
  4. Return to the Dashboard to see the plan summary.
About 5 minutes, monthly

Record a month

  1. Add this month's purchase in Transactions.
  2. Log any dividend in Dividends & income.
  3. Check Allocation for any holding above its limit.
  4. Note any decision and the reason for it.
About 30 minutes, yearly

Review and hand over

  1. Work through the Scorecard and clear any Gap you can.
  2. Update and re-sign your Policy statement.
  3. Run the Stress test with this year's assumptions.
  4. Save a backup file and store it with your will.
